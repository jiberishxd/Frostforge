# Frostforge stone interface frame

Generated with the built-in image-generation tool on September 26, 2026 after the owner requested gritty Warcraft stone buttons and borders. The original PNG is retained here. Only a square crop of the central rough stone is used in the final interface. The decorative border experiment was rejected by the owner as too heavy and stretched; the addon instead uses native Blizzard borders and desaturated, blue-tinted Blizzard button bevels. `tools/build_branding.py` exports the center tile.

## Prompt

Use case: stylized-concept. Asset type: production game UI nine-slice frame texture for a World of Warcraft addon called Jiberish's Frostforge. Create ONE square 1024x1024 raster texture, exact front-on orthographic flat view of a chunky rectangular Warcraft fantasy interface frame, filling the canvas edge to edge. Critical composition: a continuous very thick decorative border occupies the outer 12.5 percent of all four sides, and each square corner occupies 12.5 percent. The central 75 percent is a seamless-looking dark charcoal rough basalt slab, relatively even low contrast so white text will be legible. Border: heavily weathered, hand-painted sculpted gunmetal and carved slate, thick chipped bevels, irregular nicks, deep fissures, hammered wrought iron corner reinforcements and a few small battered rivets. The gritty chunky tactile visual language of the original World of Warcraft interface and Northrend fortress masonry. Stone and metal, not smooth UI outlines. Cool grey stone, blue-grey steel, traces of old muted bronze wear, very subtle icy blue frost caught in cracks. No neon, no glowing lines, no polished chrome, no rounded pill corners, no glass, no clean modern gradients. Upper/left facets softly lit, lower/right facets dark. Each edge has fairly uniform thickness across its length so it can stretch in a nine-slice interface. No perspective, no surrounding scene, no cast shadow outside the frame, no text, no runes, no logos, no skulls, no characters, no labels, no diagram. Opaque full-canvas game texture. The frame should feel like heavy ancient stone masonry bound in hand-forged iron, rugged and unmistakably Warcraft in spirit.
