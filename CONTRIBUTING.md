# Contributing

Discuss ideas and questions in [The Igloo Discord](https://discord.com/servers/igloo-460933747731070996). Keep pull requests focused and explain the change and checks performed.

Preserve saved settings, combat protections, provider-owned frames and artwork provenance. [Build and validation notes](docs/maintainer/README.md).

Source artwork is maintained separately. Normal checks and packages use the committed runtime PNGs; see [artwork maintenance](docs/maintainer/ARTWORK.md) before rebuilding images.
