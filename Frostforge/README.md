# Jiberish's Frostforge

Class, race and faction artwork for portraits, unit frames, cast bars, the minimap and action bars.

## Install

1. Choose the download for your game client: Retail or Forever.
2. With WoW closed, place this entire `Frostforge` folder in `Interface/AddOns/`. The manifest must be at `Interface/AddOns/Frostforge/Frostforge.toc`.
3. Restart WoW, enable **Jiberish's Frostforge**, and follow the first-launch setup tour. Open settings anytime with `/frostforge`, the AddOn Compartment, or the optional minimap icon.

Keep every file in this folder. Updates replace the addon folder; keep your `WTF` folder and saved settings. If upgrading from the old **JiberishUI** folder, follow the [one-time settings transfer](https://github.com/jiberishxd/Frostforge/blob/main/docs/GETTING-STARTED.md#upgrading-to-frostforge) before removing it.
