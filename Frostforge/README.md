# Jiberish's Frostforge

Install this complete `Frostforge` folder in `Interface/AddOns/`, restart WoW and follow the setup tour. Open settings with the blue **Frostforge** row after **AddOns** in the Escape menu, `/frostforge`, the AddOn Compartment or the optional minimap icon.

Use the package for your client. Updates replace the addon folder; keep your `WTF` folder and saved settings. Upgrading from `JiberishUI`? Follow the [one-time settings transfer](https://github.com/jiberishxd/Frostforge/blob/main/docs/GETTING-STARTED.md#upgrading-to-frostforge) first.
