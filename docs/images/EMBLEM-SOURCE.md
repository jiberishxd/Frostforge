# Documentation emblem provenance

`emblem.png` is a 256 × 256 documentation derivative of the existing 1254 × 1254 branding image (`artwork/branding/curseforge-logo-v1.png` in the local artwork workspace). No new emblem was generated for this documentation update. The retained original generation prompt follows.

## Generation prompt

Use case: logo-brand.
Asset type: finished square PNG project avatar for a World of Warcraft decorative UI addon, suitable for CurseForge. Generate one image at 1024x1024 pixels, aspect ratio exactly 1:1.
Primary request: Create an original, polished fantasy emblem representing ornate character portrait frames and personal identity. The addon decorates native player, target, focus, action bars and minimap with sculpted class/race/faction artwork. The name is undecided, so the logo must contain absolutely no letters or words.
Subject: A single bold, front-facing circular portrait-frame crest, richly sculpted in aged gold with a few dark slate stone insets and restrained brown leather details. In the center, a clean original four-point compass star forged from gold, inside a deep charcoal circular opening. The star and surrounding frame must read together as one memorable compact icon. Hand-painted high-fantasy game-interface craftsmanship, chunky beveled edges, handsome precise highlights, restrained surface texture. Keep ornament large and structural, not a mass of tiny filigree. Symmetric overall silhouette, subtly pointed at top and bottom; no wings, weapons, faces or skulls.
Composition: Emblem centered and filling about 78 percent of the square, complete visible edges and generous safe margin. Dark charcoal opaque background with extremely subtle stone texture and vignette. High contrast and recognizable silhouette at 64x64 pixels. No mockup, no gallery sheet, no border outside the emblem, no typography, no watermarks. Original design: do not copy World of Warcraft, Blizzard, Alliance, Horde or class logos. Deliver only the finished square image.
