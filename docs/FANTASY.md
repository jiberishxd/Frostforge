# Current fantasy-artwork scope

The previous multi-theme renderer and action-bar docking system have been replaced by the Phase 1 prototype.

Only Retribution Paladin artwork for minimap, player, target and MainActionBar is active. Use the [current controls](../README.md#controls) and [Phase 1 validation checklist](VALIDATION.md). Older crest sliders, colors, class/race catalogs and hub docking controls are not loaded or packaged.

Previous implementations are preserved in Git history; their live results do not establish compatibility for this refactor.
